# 🎬 CoHE – Historical Slider

## 📌 About
CoHE is an interactive web application featuring a historical timeline slider with smooth and engaging animations.  
The project focuses on delivering a visually rich experience using GSAP for advanced animation control.

## ✨ Features
- 🎞 Animated historical timeline slider
- 🎨 Smooth transitions and micro-interactions
- ⚡ High-performance animations with GSAP
- 📱 Fully responsive (mobile + desktop)
- 🖱 Optimized for user interaction
